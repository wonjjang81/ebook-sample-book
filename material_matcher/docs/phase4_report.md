# 4단계 완료 보고서: 로컬 DB 및 FAISS 유사도 검색 모듈 개발

## 개발 완료 항목

스마트폰 내부(On-Device)에서 인터넷 연결 없이 수만 개의 자재 중 가장 비슷한 제품을 0.01초 만에 찾아내는 핵심 검색 엔진 모듈(`search_engine.py`) 개발을 완료했습니다.

### FAISS 기반 로컬 벡터 검색 엔진 구축

Facebook에서 개발한 고속 유사도 검색 라이브러리인 `FAISS`를 활용하여 로컬 인덱스를 구축했습니다. 

*   **검색 알고리즘 최적화:** 3단계에서 추출된 특징 벡터가 이미 L2 정규화(길이가 1.0)되어 있다는 점을 활용하여, FAISS의 `IndexFlatIP(내적 검색)` 방식을 적용했습니다. 이는 정규화된 벡터 간의 내적이 곧 '코사인 유사도(Cosine Similarity)'와 완벽히 일치하므로, 연산 속도가 가장 빠르고 정확합니다.
*   **커스텀 ID 매핑:** `IndexIDMap` 래퍼를 사용하여 FAISS 내부에 저장되는 벡터들에 고유한 `vector_id`를 부여했습니다. 이를 통해 검색 결과로 반환된 벡터가 실제 어떤 자재인지 추적할 수 있습니다.
*   **영구 저장소 연동:** 앱을 껐다 켜도 데이터가 유지되도록, 생성된 인덱스를 로컬 파일(`materials.faiss`) 형태로 저장하고 불러오는 기능을 구현했습니다.

### SQLite 메타데이터 결합 및 최종 결과 도출

단순히 "비슷한 벡터를 찾았다"에서 끝나는 것이 아니라, 사용자에게 의미 있는 정보를 제공하기 위해 1단계에서 구축한 SQLite DB와 검색 엔진을 매끄럽게 연결했습니다.

| 처리 단계 | 상세 내용 |
| :--- | :--- |
| **1. 벡터 검색** | 1280차원의 쿼리 벡터를 FAISS에 입력하여, 유사도가 가장 높은 상위 5개의 `vector_id`와 `유사도 점수(Score)`를 도출합니다. |
| **2. 메타데이터 조회** | 도출된 `vector_id` 리스트를 SQLite DB에 전달하여, 해당하는 자재의 제품명, 품번, 브랜드, 썸네일 이미지 경로 등의 상세 정보를 일괄 조회(Batch Select)합니다. |
| **3. 결과 병합** | 조회된 자재 정보에 FAISS에서 계산된 유사도 점수를 추가하고, 점수가 높은 순서대로 정렬된 최종 JSON 형태의 배열 리스트를 반환합니다. |

테스트 스크립트를 통해 더미 벡터를 삽입하고 검색을 수행한 결과, 유사도 점수와 함께 자재의 상세 정보(예: `[SH-FM-0001] 무광 블랙 필름 (유사도: 0.7560)`)가 정확하게 반환되는 것을 검증했습니다.

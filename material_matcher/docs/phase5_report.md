# 5단계 완료 보고서: 촬영 가이드 UI 및 화이트 밸런스 보정 기능 개발

## 개발 완료 항목

스마트폰 카메라 화면 위에 오버레이를 그려 사용자가 최적의 사진을 찍을 수 있도록 유도하고, 기준 색상재(백색 물체)의 상태를 실시간으로 알려주는 UI 가이드 모듈(`camera_guide.py`) 개발을 완료했습니다.

### 실시간 피드백 및 상태 표시 UI 구현

사용자가 카메라를 비추는 환경과 물체의 상태를 분석하여 3가지 상태로 직관적인 피드백을 제공합니다. 화면 테두리의 색상과 하단의 텍스트 메시지가 실시간으로 변경됩니다.

| 상태 분류 | 피드백 색상 | 조건 및 안내 메시지 |
| :--- | :--- | :--- |
| **어두운 환경** | 🟠 주황색 (Warning) | 이미지의 평균 밝기가 임계값 이하일 때 발생.<br>`"Too dark! Turn on the lights."` |
| **부적합 (기준 없음)** | 🔴 빨간색 (Error) | 화면 내에 백색 물체가 없거나 비율/균일도가 맞지 않을 때 발생.<br>`"백색 물체가 너무 작거나 없습니다."` 등 상세 사유 표시 |
| **촬영 가능 (적합)** | 🟢 초록색 (Success) | 조명이 적절하고, 유효한 백색 물체가 감지되었을 때 발생.<br>`"White reference OK! Ready to capture."` |

특히, '촬영 가능' 상태가 되면 앱이 감지한 **백색 물체의 외곽선(Contour)을 찾아 초록색 선으로 강조**해 줌으로써, 사용자가 "앱이 기준점을 정확히 인식했구나"라고 확신할 수 있게 합니다.

### 패턴 중앙 정렬 오버레이 (Center Crop Guide)

AI 모델은 이미지의 중앙 영역(60%)을 잘라내어 분석합니다. 사용자가 이 영역에 맞춰 자재를 촬영할 수 있도록 돕는 시각적 가이드를 추가했습니다.

*   화면 중앙에 점선/실선 형태의 정사각형 가이드라인을 배치했습니다.
*   가이드라인 바깥쪽 영역은 30% 투명도의 검은색으로 어둡게 처리(Dimming)하여, 사용자의 시선이 자연스럽게 중앙의 밝은 사각형 영역으로 집중되도록 유도합니다.
*   가이드 상단에 `"Center the material pattern here"` 텍스트를 배치하여 직관성을 높였습니다.

테스트 스크립트를 통해 3가지 상황(어두움, 백색 없음, 정상)에 대한 합성 이미지를 성공적으로 생성하고 검증을 완료했습니다.

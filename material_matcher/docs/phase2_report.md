# 2단계 완료 보고서: 이미지 전처리 모듈 개발

## 개발 완료 항목

### 1. 백색 물체 자동 감지 및 적합성 검증 기능
기존의 고정된 'A4 용지 영역' 방식을 폐기하고, 화면 내 어디에 있든 백색 물체를 자동으로 찾아내어 기준 색상재로 적합한지 판단하는 알고리즘을 구현했습니다.

**적합성 검증 기준 (`config.py` 및 `preprocessing.py` 반영):**
*   **면적 비율 검증:** 전체 이미지 대비 5% ~ 30% 크기일 때만 유효 (너무 작으면 기준이 될 수 없고, 너무 크면 자재를 가림)
*   **HSV 색상 기반 감지:** 조명에 의해 노랗게/파랗게 변한 백색 물체도 감지할 수 있도록 명도(Value)는 높고 채도(Saturation)는 낮은 영역을 동적으로 마스킹
*   **균일도(Uniformity) 검사:** 감지된 영역의 픽셀 표준편차를 계산하여 무늬가 있거나 그림자가 심하게 진 물체를 걸러냄 (표준편차 15 이하)

### 2. 동적 화이트 밸런스 자동 보정
*   검증을 통과한 백색 물체 영역의 평균 BGR 값을 추출
*   해당 값을 순백색(255, 255, 255)으로 스케일링하는 보정 계수를 계산
*   이 계수를 전체 이미지에 곱하여 노란빛(전구색)이나 푸른빛 조명을 제거하고 자재 본연의 색상을 복원

### 3. AI 모델 입력 규격 처리
*   가장 핵심이 되는 이미지의 중앙 부분을 기준으로 짧은 변에 맞춰 정사각형 크롭
*   MobileNetV3의 기본 입력 규격인 224×224 크기로 리사이징 (Interpolation 적용)
*   PyTorch 모델 호환을 위해 BGR 포맷을 RGB로 변환

### 4. 통합 파이프라인 및 테스트 완료
*   `run_pipeline(image_path)` 메서드를 통해 '밝기 체크 -> 백색 물체 감지 -> 화이트 밸런스 보정 -> 크롭 및 리사이징'의 전체 흐름을 한 번에 실행
*   더미 이미지를 활용한 테스트 스크립트(`tests/test_preprocessing.py`) 작성 및 검증 통과 (Success: True, Final shape: 224x224x3)

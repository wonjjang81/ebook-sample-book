# 3단계 완료 보고서: 온디바이스 AI 특징 추출 모듈 개발

## 개발 완료 항목

스마트폰 내부(On-Device)에서 인터넷 연결 없이 빠르게 동작할 수 있도록 최적화된 AI 특징 추출 모듈 개발을 완료했습니다. 이 모듈은 전처리된 이미지를 입력받아 수학적 벡터로 변환하는 핵심 역할을 수행합니다.

### 경량화 AI 모델 적용 및 설정

모바일 환경에서의 연산 속도와 정확도를 고려하여 `MobileNetV3-Large` 아키텍처를 채택했습니다. ImageNet 데이터셋으로 사전 학습된 가중치(Pre-trained Weights)를 로드하여 자재의 기본적인 시각적 특징(패턴, 질감, 색상)을 인식할 수 있는 상태로 초기화했습니다. 자재의 종류를 분류(Classification)하는 것이 아니라 특징을 비교하는 것이 목적이므로, 모델의 마지막 분류 레이어를 제거하고 그 직전의 특징 벡터를 추출하도록 구조를 수정했습니다. 테스트 결과, `config.py`에 정의된 차원 수를 960에서 1280으로 업데이트하여 정확한 벡터를 추출하도록 반영했습니다.

### 데이터 변환 및 검색 최적화 프로세스

입력된 이미지가 AI 모델과 검색 엔진에서 최적의 성능을 낼 수 있도록 두 가지 정규화 과정을 구현했습니다.

| 정규화 단계 | 목적 및 처리 내용 | 결과 |
| :--- | :--- | :--- |
| **이미지 텐서 정규화** | 224×224 크기의 RGB 이미지를 PyTorch Tensor로 변환하고, 모델 학습 기준에 맞춰 픽셀 값의 평균과 표준편차를 정규화합니다. | 모델 인식률 및 정확도 향상 |
| **벡터 L2 정규화** | 모델에서 추출된 1280개의 숫자로 이루어진 벡터의 전체 길이를 1.0으로 스케일링합니다. | 코사인 유사도 검색 속도 및 정확도 극대화 |

테스트 스크립트를 통해 추출된 벡터의 형태가 `(1280,)`이며, L2 노름(Norm) 값이 정확히 `1.0000`으로 출력됨을 검증 완료했습니다.

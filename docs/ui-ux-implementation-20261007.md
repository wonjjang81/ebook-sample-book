# E-샘플북 UI/UX 권장안 구현 결과

작성일: 2026-10-07. 승인된 `design-review-20261007/design-preview.html`의 권장안을 기존 앱에 적용했다. 운영 배포·Git 커밋은 수행하지 않았다.

## 구현 범위

- 아이보리 배경, 네이비 포인트, 흰색 사이드바와 카드, 시스템 글꼴 적용. 사용하지 않는 외부 웹폰트 요청 제거.
- 목록: 제목·현재 카테고리 경로 표시, 접이식 필터, 활성 조건별 해제 칩, 오름/내림차순을 명시한 정렬 선택.
- 카드: 과도한 확대 효과 제거, 브랜드·제품 계열·품번·제품명 중심으로 정보 축약, 선택/찜 버튼 44px, 키보드 Enter로 상세 진입. 기존 반복 패턴 이미지 표시 유지.
- 모바일: 사이드바 기본 닫힘과 메뉴 열기 버튼, 2열 카드(340px 미만 1열), 내보내기 버튼 줄바꿈. 잘못된 sidebarOpen 저장 값 복구 처리.
- 사이드바: 쇼룸/사진 검색/설정/관리 버튼에 펼친 상태에서 기능명 표시. 편집 활성화 시에만 카드 편집 버튼 표시.
- 상세: 데스크톱 이미지와 정보 영역을 2열로 배치, 상단 사양 배지를 문장으로 정리. 이미지 교체·서버 업로드·확대 기능 유지.
- 선택/찜: 프로젝트 선택·저장·생성 UI를 하나의 공통 JSX로 통합, 새 프로젝트 입력은 접어서 표시. 생성·저장 피드백을 toast로 변경. 브라우저 저장 범위 안내.
- 관리자: 동작하지 않는 PDF 업로드 메뉴 숨김. 샘플/카테고리 로컬 저장과 서버 이미지 저장 구분 안내. 기존 PDF 내보내기·미리보기 유지.

## 보존한 시스템

제품 ID, 카테고리 계층, URL 라우트, 프로젝트·선택·찜·메모 localStorage 형식을 변경하지 않았다. Google 관리자 인증, R2/D1 설정, 서버 API, 제품 데이터는 이번 작업에서 변경하지 않았다. 기존 작업 파일과 미커밋 변경 사항을 유지했다.

편집 모드는 UI 표시 조건이며 서버 권한을 새로 부여하지 않는다. 로컬 샘플/카테고리/프로젝트 편집은 서버 공동 편집으로 전환되지 않았다.

빌드에는 500KB 초과 청크 경고가 남아 있다. 이번 작업은 광범위한 코드 분할·시스템 개편 없이 승인된 화면 변경에 집중했다.

## 검증 제한 및 배포 전 확인

- 로컬 정적 미리보기에는 운영 R2 이미지 API가 연결되지 않는다. 서버 업로드 이미지는 일부 `이미지 없음`으로 표시되며, 저장소에 포함된 LX 이미지는 표시 확인했다. 운영 이미지가 삭제되었다는 의미는 아니다.
- 프로젝트 생성 테스트 중 기존 브라우저 alert가 자동화를 막았다. 새 탭에서 생성된 프로젝트 이름의 유지까지 확인했지만, 최종 toast 저장과 상세/관리 화면의 최종 브라우저 상호작용 검증은 추가 확인이 필요하다. 생성/저장 alert를 toast로 바꾼 최종 소스는 타입·빌드·79개 테스트를 재통과했다.
- 운영 로그인·R2 쓰기 테스트는 수행하지 않았다. 서버 코드는 변경하지 않았다.
- 미리보기: `http://127.0.0.1:4173/` (로컬 서버 실행 중에만 접근 가능).
- 화면 캡처: 작업공간의 `design-review-20261007/implemented-desktop.png`.
- 운영 배포 시에는 기존 미커밋 작업이 많으므로 변경 범위를 먼저 분리·검토해야 한다. 전체 파일을 일괄 커밋하지 않는다.

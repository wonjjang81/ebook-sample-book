# 영림 필름 자재 등록

공식 출처: https://yl.co.kr/product/category?pi_categoryCode=080100

2026-10-07 공식 페이지와 해당 페이지의 공개 categorySearch API를 확인했다. 전체 페이지 합계 359개를 수집했으며 품번과 ID의 중복 여부를 검증한다. 영림 표기와 구분 문자가 섞인 코드에서 필름 품번을 분리하고 공백을 정리했다. 필름 품번이 없는 4개 제품은 공식 영림 번호를 유지한다.

- 필름 > 영림 > 인테리어필름&시트 > 디자인 분류.
- 솔리드 94, 솔리드 엠보 26, 우드 139, 패브릭 18, 스톤&마블 36, 레더&글리터 12, 메탈 18, 공식 분류 미지정 16.
- 제품명·품번·공식 디자인 및 옵션을 반영한다. 색상과 규격은 추측하지 않았다. 방염가능필름은 선택 가능한 사양이며 실제 출고 제품 인증을 보장하는 문구로 바꾸지 않는다.
- 공식 S3 공개 이미지 URL을 참조한다. R2에 파일을 업로드하거나 복사하지 않았다. 외부 이미지 서비스의 가용성과 CORS 설정에 따라 표시용 경계 보정이 원본 반복으로 복귀할 수 있다.
- 기존 카테고리와 사용자 편집, 3M 샘플은 보존한다.
